Указать не менее 10 базовых команд Git и краткое описание.
Обязательно включить: git clone, git status, git add, git commit, git push.
1. git clone — скачать репозиторий с GitHub или другого сервера себе на компьютер
2. git status — посмотреть, что изменилось в проекте и какие файлы сейчас изменены
3. git add — добавить изменённые файлы, чтобы потом их можно было сохранить
4. git commit — сохранить сделанные изменения и написать к ним комментарий
5. git push — отправить свои изменения на удалённый репозиторий
6. git pull — скачать с сервера последние изменения в проекте
7. git init — создать новый Git-репозиторий в папке с проектом
8. git branch — посмотреть или создать ветки проекта
9. git checkout — перейти на другую ветку или вернуться к определённой версии
10. git merge — объединить изменения из одной ветки с другой
